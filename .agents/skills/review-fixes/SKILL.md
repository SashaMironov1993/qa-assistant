# Замечания по ревью

Найди черновик указанной задачи с заполненным блоком `СТАРТ БЛОКА ЗАМЕЧАНИЯ ПО РЕВЬЮ` — `КОНЕЦ БЛОКА ЗАМЕЧАНИЯ ПО РЕВЬЮ`. Если замечания неоднозначны или затрагивают новое требование, попроси уточнение вместо догадки.

Исправь только относящийся к замечаниям документ. Сохрани ссылки на источники и открытые вопросы; не подменяй замечание подтверждением неописанного поведения. Затем сверь результат с исходными материалами через `fact-checking` и снова передай тот же черновик пользователю на ревью. Не вписывай `РЕВЬЮ ПРОЙДЕНО` сам и не переноси файл.
